# AI Resume Screener

[![Python Version](https://img.shields.io/badge/python-3.8%2B-blue)](https://www.python.org/downloads/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)
[![Streamlit](https://img.shields.io/badge/streamlit-1.0%2B-red)](https://streamlit.io/)

An intelligent resume screening application powered by semantic search and Google Gemini AI. Automatically evaluate candidates against job descriptions with detailed matching analysis, skill assessments, and personalized recommendations.

## 🎯 Overview

The AI Resume Screener leverages modern NLP techniques and Large Language Models to provide HR teams and recruiters with:

- **Automated Resume Analysis**: Extract and analyze resume content intelligently
- **Semantic Matching**: Find relevant resume sections using advanced semantic search
- **AI-Powered Evaluation**: Leverage Google Gemini for nuanced candidate assessment
- **Comprehensive Scoring**: Get detailed scores, skill matching, and recommendations
- **Batch Processing**: Screen multiple resumes efficiently

## ✨ Features

- 📄 **Multi-Format Support**: Upload PDF and TXT resumes
- 🔍 **Intelligent Text Processing**: Extract, clean, and chunk resume content
- 🧠 **Semantic Embeddings**: Generate embeddings using Sentence Transformers
- 💾 **Vector Database**: Store and retrieve embeddings with ChromaDB
- 🎯 **Smart Retrieval**: Fetch job-relevant resume sections via semantic search
- 🤖 **AI Evaluation**: Use Google Gemini for intelligent candidate-job matching
- 📊 **Detailed Reports**: Get comprehensive scores, skills analysis, and recommendations
- ⚡ **Batch Screening**: Process single or multiple resumes in one go
